# 为什么超市里的东西总是越来越贵（C002）

## 口播稿（源文件）

你有没有发现，十年前的十块钱能买一大袋零食，现在却只够买一瓶饮料？
这不是你记错了，而是钱变毛了，你手里钱的购买力一直在悄悄下降。
商品还是那些商品，可印出来的钱越来越多，钱一多，东西自然就涨价了。
超市进货要加价，运输要加价，员工工资也要涨，这些成本最后都算进你买的商品里。
所以同样一张一百块，能买到的东西一年比一年少，这就是东西越来越贵的原因。
