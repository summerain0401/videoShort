# 为什么工资总涨不过物价（C003）

> 主题：为什么工资总涨不过物价 ｜ 生成方式：WorkBuddy 产稿（生态内 LLM，零 API key）

## 口播稿（源文件）

你有没有发现，工资明明在涨，钱却越来越不经花？十年前一百块能买一周菜，现在进超市一转眼就没了。

其实这不是错觉。工资涨的是数字，物价涨的是生活成本。物价跑得比工资快，你的购买力就在偷偷缩水。

为什么会这样？因为物价是被大家一起抬上去的：原材料涨、人工贵、房租高，每一环成本都悄悄加进商品价格里，买单的还是你。

更要命的是，工资总是慢半拍。企业要等行情稳了才舍得加薪。等你拿到加薪通知，物价早就又涨了一轮。

所以记住，看工资别只看数字，要看它买得到什么。与其干等加薪，不如先学会让钱生钱，这才是对抗物价的长期办法。
