### 4 项根因 + 修复链

#### 根因 1：白闪
- **根因**：`NarrationScene` 每场景固定 0.2s 淡出到 opacity=0，淡出后露出 `Main.tsx` 的暖白底 `#FFF8EE`，场景叠加时呈全屏白闪
- **修复**：在 `Main.tsx` 改用**交叉溶解**（场景 Sequence 重叠 CROSS_DISSOLVE 秒，相邻场景 opacity 交叉渐变，不整场景淡出到根底）；`NarrationScene` 拆为两个独立两点 interpolate 取最小（`fadeInOpacity`/`fadeOutOpacity`），避免 inputRange 退化（`[0,0,...]` / `[...,36,36]`）
- **附加 bug**：原 4 点 interpolate 修复有残留 bug（fadeIn=false 时 `Math.max(0,0)=0` 与首项相等；fadeOut=false 时 `dur-0=dur` 与末项相等），最终改双两点方案彻底消除
- **修复点**：`remotion/src/scenes/NarrationScene.tsx`、`remotion/src/Main.tsx`

#### 根因 2：静态片头
- **根因**：`IntroScene` 静态标题卡占 0-3s，第 0 秒第一帧是黑底+标题而非人物
- **修复**：`Main.tsx` 删除 IntroScene 渲染分支；正文从 frame 0 直接开始；`Root.tsx` 时长算法去掉 +3s 片头余量，只加 OUTRO + CROSS_DISSOLVE；`HookTitle.tsx` 新建悬浮标题贴纸（在 S01 顶部"？小包装更贵"）
- **修复点**：`remotion/src/Main.tsx`、`remotion/src/Root.tsx`、`remotion/src/components/HookTitle.tsx`

#### 根因 3：信息可视化空缺（overlays=0）
- **根因链（3 层）**：
  1. **口播稿无数字**：原口播稿全文中文叙述（"更贵/一百克"），无任何阿拉伯数字 → `detect_overlays` 正则 `\d+` 匹配不到 → 0 overlays
  2. **write_outputs 丢弃 overlay**：`from-script` 分支只把 characters/props 传入 plan_scenes；`write_outputs` 重建 elements 时只保留 character/prop，overlay 元素被丢
  3. **auto_overlays 兜底过宽**：无数字时也按"大包/小包/单价/包装"等关键词触发纯文本 vs-card（"大包装 vs 小包装"）/equation（"总价 ÷ 重量"），在讲解段是噪音
- **修复（4 项）**：
  1. **口播稿**加入具体数字对比："一包 50 克的小包装要 5.5 块"、"小包装 100 克卖 9.9 块，大包装 100 克只要 7.5 块，差的这 2.4 块"
  2. **detect_overlays 增强**：价格对优先（"9.9 块 vs 7.5 块"）；算式触发词（"除以/单价/每克/折合成"）追加 equation；price-tag 优先取价格
  3. **from-script plan_scenes 透传 overlays**；**write_outputs 通用挂接** overlays
  4. **auto_overlays 收紧**：nums 为空直接 return []；兜底挂接移到 subdivide **之前**（父场景层）；subdivide 后子片 i>0 清空 overlays（避免同一父场景的 vs-card 连续重复挂屏）
- **修复点**：`scripts/generate-story.py`、`scripts/build-timeline.py`、`02_项目/C008_小包装更贵/script/口播稿.txt`
